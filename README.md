# SmartScan

SmartScan is a low-cost autonomous/semi-autonomous mobile robotic
system designed for indoor mapping and spatial scanning.

The repository contains the documentation, hardware-related files,
firmware, ROS 2 workspace, SLAM, navigation, scripts, tests and
experimental data associated with the SmartScan project.
